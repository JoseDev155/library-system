# Carpetas de agentes

Actualiza la estructura de carpeta de agentes, con lso archivos necesarios para cada agente. Asegúrate de incluir los siguientes elementos en cada carpeta de agente:

* `.agents/`: Llenala con los archivos necesarios para cada agente, incluyendo su configuración y scripts específicos.
* `.antigravity/`: Incluye los archivos de configuración y scripts necesarios para el IDE Antigravity. Ademas, este contiene los prototipos del frontend
* Actualiza el `CLAUDE.md` y el `AGENTS.md` si lo requieren.
* Actualiza el `spec.md` para reflejar la nueva estructura de carpetas y los archivos necesarios para cada agente.
