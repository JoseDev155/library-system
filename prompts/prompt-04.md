# "Deploy" en GCP

1. Crea un archivo markdown con los pasos para "desplegar" el proyecto en Google Cloud Platform (GCP).
2. Crea el archivo en la carpeta que sea apropiada tecnicamente. Si no existe la carpeta, creala.
3. Si ese archivo consideras que tiene pasos que no deberian incluirse en el repositorio, agregala al `.gitigonre` de la raiz del proyecto.
4. Se creara un Windows Server 2022 en GCP, con la configuración necesaria para ejecutar el proyecto.
5. El servidor se debe configurar para que funcione como un equipo cliente, no como servidor.
6. En el servidor se instalara: VS Code, Python 3.15.*, Python 3.9.*, Bun, Git.
