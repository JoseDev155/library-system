# Reglas del Backend

* POO estricta en casi todas las capas
* Puedes ser flexible en la capa `security/`, `config.py` y `main.py`
* Los tests unitarios deben ser escritos en `tests/` y deben cubrir al menos el 80% del código
* Usa `pytest` para los tests unitarios

Tareas:

* Adaptar el `spec.md` con las reglas del backend y el uso de `pytest` para los tests unitarios
* Ejecutar los tests unitarios hasta que el backend este completo y funcional
